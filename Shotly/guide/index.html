Shotly: step-by-step guide

Repository · Download

Step 1. Installation

  1. Download the installer from the Releases page. Requires Windows 10 or 11.
  2. Run it — Shotly settles into the tray. Everything it needs is inside the app; nothing is downloaded afterwards.
  3. Autostart is offered in settings. Starting with Windows only puts Shotly in the tray — it never opens the overlay on its own.

Step 2. Taking a shot

  1. Press Prnt Scrn, or left-click the tray icon. The screen dims — all your monitors at once.
  2. Drag a frame around what you need. The size shows in a label next to it.
  3. Adjust it: move the frame by dragging inside it, resize by the eight handles around the edge.
  4. Double-click the selection to copy it, or use the buttons that appear beside the frame.

Ctrl + A selects the whole screen at once. The right mouse button clears the selection, and a second press closes the overlay.

Step 3. Drawing on it

Pick a tool from the strip: pencil, line, arrow, rectangle, marker or text. Any colour from the palette — or your own through the system colour picker — and any of four thicknesses.

  • You can draw anywhere on the screen, not only inside the frame. Only the selected area goes into the file or the clipboard; the rest is cropped away.
  • Hold Shift while drawing for a straight line or a perfect square.
  • Ctrl + Z undoes the last shape.
While a tool is active, clicking outside the frame draws instead of starting a new selection. To select a different area, switch the tool off — click its button again, or press Esc.

Esc walks back one step at a time: text, then palette, then tool, then out of the overlay.

Step 4. Saving the result

ActionHow
CopyCtrl + C, a double click on the selection, or the button
Save to a fileCtrl + S or the button — PNG, JPG or BMP
PrintCtrl + P, through the system dialog

Shots go to your pictures folder by default; you can point Shotly at any other one in settings, or have it ask for the path every time.

Step 5. The whole screen at once

Two more global shortcuts grab everything without the overlay — straight to a file with Shift + Prnt Scrn, or to the clipboard with Ctrl + Prnt Scrn. Both are off by default; switch them on in settings, where all three shortcuts can also be reassigned.

Step 6. File names

The pattern is set on the Formats tab, with a live example right under the field. The default is a plain Screenshot_ plus a number.

CodeWhat it becomes
%nthe smallest free number in the folder: 1, 2, 3 …
%03nthe same with leading zeros: 001, 002
%Y %m %dyear, month, day
%H %M %Shours, minutes, seconds
Numbering starts from one, not from the last shot plus one. With Screenshot_133 and Screenshot_135 already in the folder, the next one becomes Screenshot_134 and the gap closes. A number counts as taken in any of the supported formats.

Step 7. Settings

Open them from the tray menu — four tabs:

  • General — autostart, notifications, remembering the last frame, including the cursor in the shot, save folder, interface language, reset.
  • Hotkeys — the three global shortcuts.
  • Formats — PNG, JPG or BMP, JPEG quality, the file name pattern, and whether to ask for the path on every save.
  • Updates — notifications about new versions, checking and installing.

Shotly: пошаговое руководство

Репозиторий · Скачать

Шаг 1. Установка

  1. Скачай установщик со страницы Releases. Нужна Windows 10 или 11.
  2. Запусти — Shotly поселится в трее. Всё нужное лежит внутри программы, ничего потом не докачивается.
  3. Автозапуск включается в настройках. Старт вместе с Windows только кладёт Shotly в трей — оверлей сам по себе не открывается.

Шаг 2. Как сделать снимок

  1. Нажми Prnt Scrn или кликни левой кнопкой по иконке в трее. Экран затемнится — сразу на всех мониторах.
  2. Растяни рамку вокруг нужного. Размер виден в подписи рядом.
  3. Поправь её: двигай, потянув изнутри, меняй размер за восемь ручек по краям.
  4. Двойной клик по выделению копирует его, либо жми кнопки, которые появляются рядом с рамкой.

Ctrl + A выделяет сразу весь экран. Правая кнопка мыши сбрасывает выделение, повторное нажатие закрывает оверлей.

Шаг 3. Рисование поверх

Выбери инструмент на панели: карандаш, линия, стрелка, прямоугольник, маркер или текст. Любой цвет из палитры — или свой через системный выбор цвета — и любая из четырёх толщин.

  • Рисовать можно по всему экрану, не только внутри рамки. В файл и буфер уходит выделенная область, остальное обрезается.
  • Зажми Shift при рисовании — получится ровная линия или квадрат.
  • Ctrl + Z отменяет последнюю фигуру.
Пока выбран инструмент, клик за рамкой рисует, а не начинает новое выделение. Чтобы выделить другую область, отключи инструмент — повторным кликом по его кнопке или клавишей Esc.

Esc отступает по шагу: текст, потом палитра, потом инструмент, потом выход из оверлея.

Шаг 4. Что делать с результатом

ДействиеКак
СкопироватьCtrl + C, двойной клик по выделению или кнопка
Сохранить в файлCtrl + S или кнопка — PNG, JPG или BMP
НапечататьCtrl + P, через системный диалог

По умолчанию снимки складываются в папку с изображениями; в настройках можно указать любую другую или попросить спрашивать путь при каждом сохранении.

Шаг 5. Весь экран сразу

Ещё два глобальных сочетания снимают всё без оверлея — сразу в файл по Shift + Prnt Scrn или в буфер по Ctrl + Prnt Scrn. Оба по умолчанию выключены; включаются в настройках, там же все три сочетания можно переназначить.

Шаг 6. Имена файлов

Шаблон задаётся на вкладке Форматы, под полем сразу виден пример. По умолчанию это Screenshot_ и номер.

КодЧто подставляется
%nнаименьший свободный номер в папке: 1, 2, 3 …
%03nон же с ведущими нулями: 001, 002
%Y %m %dгод, месяц, день
%H %M %Sчасы, минуты, секунды
Номер ищется с единицы, а не «последний плюс один». Если в папке уже есть Screenshot_133 и Screenshot_135, следующий снимок станет Screenshot_134 и дыра закроется. Занятым номер считается в любом из поддерживаемых форматов.

Шаг 7. Настройки

Открываются из меню трея, четыре вкладки:

  • Основные — автозапуск, уведомления, память о рамке выделения, курсор в кадре, папка сохранения, язык интерфейса, сброс настроек.
  • Горячие клавиши — три назначаемых сочетания.
  • Форматы — PNG, JPG или BMP, качество JPEG, шаблон имени файла и нужно ли спрашивать путь при каждом сохранении.
  • Обновления — уведомления о новых версиях, проверка и установка.
