Privacy

Short answer: your screenshots never leave your computer, and this page has no trackers.

The app

  • Nothing is uploaded. Shots go to your clipboard or to a folder on your disk. There is no server of ours, no link to share, no account.
  • No tracking. Shotly does not report what you capture or how often you use it.
  • Your data is local. Settings live in one file inside your user profile, next to a crash log and a small cache. Shots go to the folder you chose.
  • Nothing is fetched afterwards. Everything the app needs is inside the executable.

When it uses the network

Once: to ask GitHub whether a newer version exists, and to download it if you agree. That check can be switched off in settings. There is nothing else.

What ends up in a shot

A screenshot captures whatever is on screen at that moment, which may include private information — messages, names, documents. Shotly does not look at any of it, but you should: check the frame before you send it on.

This website

  • Simple static pages on GitHub Pages. No analytics, no trackers, no ads.
  • The site sets no cookies and collects no personal data.
  • Fonts load from Google Fonts, so that request reaches Google with your IP address, like on any site that uses a font service.
  • GitHub hosts the pages and may keep normal server logs. See the GitHub Privacy Statement.

Questions

Something unclear, or something you want changed? Write an issue on GitHub.

Приватность

Коротко: снимки никуда не уходят с твоего компьютера, а у этой страницы нет слежки.

Программа

  • Ничего не выгружается. Снимки попадают в буфер обмена или в папку на твоём диске. Нашего сервера нет, ссылки для обмена нет, аккаунта нет.
  • Никакой слежки. Shotly не сообщает никуда, что ты снимаешь и как часто пользуешься программой.
  • Данные лежат локально. Настройки — в одном файле внутри твоего профиля, рядом лог ошибок и небольшой служебный кэш. Снимки — в выбранной тобой папке.
  • Ничего не докачивается. Всё, что нужно для работы, лежит внутри exe.

Когда она выходит в сеть

Один раз: спросить у GitHub, есть ли версия новее, и скачать её, если ты согласишься. Эту проверку можно выключить в настройках. Больше ничего.

Что попадает в кадр

Снимок захватывает всё, что в этот момент на экране, — включая личное: переписку, имена, документы. Shotly в это не заглядывает, но тебе стоит: посмотри на кадр, прежде чем отправлять его дальше.

Этот сайт

  • Простые статические страницы на GitHub Pages. Ни аналитики, ни счётчиков, ни рекламы.
  • Сайт не ставит куки и не собирает личные данные.
  • Шрифты грузятся из Google Fonts, поэтому этот запрос уходит в Google вместе с твоим IP-адресом — как на любом сайте со шрифтами из сети.
  • Страницы лежат на GitHub, он может вести обычные логи сервера. Подробности — в политике GitHub.

Вопросы

Что-то непонятно или хочется изменить? Напиши в issues на GitHub.
