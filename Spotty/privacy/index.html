Privacy

Short answer: what you type stays on your computer, and this page has no trackers.

The app

  • Queries are never sent anywhere. Matching happens on your machine, against names Spotty already knows. The only exception is the one you ask for: choosing a web search opens your browser with that query, the same as typing it there yourself.
  • No tracking. Spotty does not report what you search for, what you open or how often you use it.
  • Your data is local. Settings live in %APPDATA%\Spotty; the icon and app-list cache, along with how often you have opened things, lives in %LOCALAPPDATA%\Spotty. Delete the cache and it is rebuilt.
  • Names, not contents. Spotty reads file and folder names in the folders you picked. It does not open your documents or look inside them.

When it uses the network

To ask GitHub whether a newer version exists, and to download it if you agree. That check is controlled in Settings. Beyond updates and the web searches you start yourself, there is nothing else.

This website

  • Static pages on GitHub Pages. No analytics, no trackers, no ads.
  • The site sets no cookies. Your language choice is kept in your own browser and never leaves it.
  • The search bar on the front page is a demo. It runs entirely in your browser against a made-up list, opens nothing and sends nothing.
  • Fonts load from Google Fonts, so that request reaches Google with your IP address, like on any site that uses a font service.
  • GitHub hosts the pages and may keep normal server logs. See the GitHub Privacy Statement.

Questions

Something unclear, or something you want changed? Write an issue on GitHub.

Приватность

Коротко: напечатанное остаётся на твоём компьютере, а у этой страницы нет слежки.

Программа

  • Запросы никуда не уходят. Поиск идёт на твоей машине, по названиям, которые Spotty уже знает. Единственное исключение — то, о чём ты просишь сам: выбрав поиск в интернете, ты открываешь браузер с этим запросом, ровно как если бы набрал его там.
  • Никакой слежки. Spotty не сообщает никуда, что ты ищешь, что открываешь и как часто пользуешься программой.
  • Данные лежат локально. Настройки — в %APPDATA%\Spotty; кэш иконок, список программ и частота запусков — в %LOCALAPPDATA%\Spotty. Кэш можно удалить, он соберётся заново.
  • Имена, а не содержимое. Spotty читает имена файлов и папок в выбранных тобой каталогах. Документы он не открывает и внутрь не заглядывает.

Когда она выходит в сеть

Чтобы спросить у GitHub, есть ли версия новее, и скачать её, если ты согласишься. Эта проверка настраивается. Кроме обновлений и поиска в интернете, который ты начинаешь сам, ничего больше нет.

Этот сайт

  • Статические страницы на GitHub Pages. Ни аналитики, ни счётчиков, ни рекламы.
  • Сайт не ставит куки. Выбранный язык хранится в твоём браузере и никуда из него не уходит.
  • Строка поиска на главной — демонстрация. Она работает целиком в браузере по выдуманному списку, ничего не открывает и никуда ничего не отправляет.
  • Шрифты грузятся из Google Fonts, поэтому этот запрос уходит в Google вместе с твоим IP-адресом — как на любом сайте со шрифтами из сети.
  • Страницы лежат на GitHub, он может вести обычные логи сервера. Подробности — в политике GitHub.
