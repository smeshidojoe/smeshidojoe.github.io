Spotty guide

Everything the bar can do, from installing it to the last setting. Ten minutes end to end, and you can stop after the first two sections.

Installing

  1. Download the installer Take Spotty-Setup-….exe from the releases page, or use the button on the front page.
  2. Run it No administrator rights are needed. Windows may show a blue “Windows protected your PC” window — click More info → Run anyway. Every app without a paid signing certificate gets that screen.
  3. Press Ctrl + E The bar opens by itself right after install. From then on it lives in the tray, next to the clock, and Ctrl E brings it up from any app.

The bar

Press Ctrl E, type, pick with the arrow keys, open with Enter. Close it with Esc or by clicking anywhere else — the bar never takes over your screen and never asks to be dealt with.

You do not have to finish a word. Spotty matches the letters you typed against every name it knows, so tele, tlg and eleg all find Telegram.

Nothing to set up first. The list of apps is built on the first run and kept up to date in the background. You can start using the bar immediately.

What you can find

Apps

Everything in the Start menu, including Calculator, Settings and other Microsoft Store apps. On top of that, once a day Spotty looks through all your drives and finds portable apps and games that were never installed into Start. Those show up with the folder they live in, so two copies of the same program are easy to tell apart.

Files and folders

From your Desktop, Documents and Downloads by default. Add or remove folders in Settings. Hidden files and service folders such as node_modules and .git are skipped on purpose — they would bury everything else.

Calculator

Type an expression and the answer appears as you write it: 12*(3+4)^2, 1920/16*9, sqrt(2). Enter copies the answer.

It understands + - * / // % ^ **, brackets, a comma as the decimal point, × and ÷, the constants pi, e, tau, and the functions sqrt, sin, cos, tan, asin, acos, atan, ln, log, log2, log10, exp, abs, round, floor, ceil and fact.

Commands

Start the query with > and the rest is a shell command: > ipconfig /all. It opens in a new Command Prompt window, so you can read the output instead of watching it flash by.

The web

Every search ends with “Search Google for …”, so a query never dead-ends. Start with ? to skip straight to the web: ? weather tomorrow. Type something that looks like an address — github.com — and Spotty offers to open the site instead of searching for it. The engine is yours to pick in Settings: Google, Yandex, DuckDuckGo or Bing.

Ctrl K is worth learning. It lists everything that can be done with the selected item — show in folder, copy the path, copy the name, open a terminal there, run as administrator, forget how often you have used it, hide it from results — and each action shows its own shortcut next to it.

Hiding is reversible. An item hidden with Ctrl K comes back from Settings → Hidden from Results. A hidden folder hides everything inside it, which is the quickest way to clean up a noisy results list.

Three things it does quietly

  • What you open often moves up. If you always open Telegram after typing “t”, next time it is already first. “Forget” in the actions menu resets that for one item.
  • The wrong keyboard layout still works. еудупкфь finds Telegram — the keys are in the same places, so the query is translated back before matching.
  • Abbreviations count. vsc is Visual Studio Code, ntpd is Notepad.

Updates

Two ways to be told about a new version, both set in Settings:

  • Notify Me — a notice pops up in the corner of the screen. Click it and the update downloads right in the bar, with a progress strip, then Spotty restarts.
  • Download in Background — the update downloads while you keep working. When it is ready, a Restart and Update button appears in the bar and waits there until you press it.

“Check for Updates” in the tray menu always downloads in the background.

Where things live

  • Settings — %APPDATA%\Spotty
  • Icon and app-list cache — %LOCALAPPDATA%\Spotty; safe to delete, it is rebuilt
  • A downloaded update — the _update folder next to Spotty.exe

Uninstalling

Settings → Apps → Spotty → Uninstall. The uninstaller asks whether to keep your settings, so reinstalling later picks up where you left off.

If something is off

The shortcut is taken. Another app holds it, often another launcher. Close that app or pick a different combination.

The bar opens slowly. Turn off Glass Background. The glass captures the screen underneath and blurs it on the graphics card; on older hardware plain dark is faster.

Something is missing from the results. For files, add the folder in Settings. For apps on a drive, remember that the sweep skips Windows and ProgramData, Downloads, git repositories and service programs — installers, updaters and console tools. If the app is in the Start menu, search for its Start menu name.

Anything else, or an idea for the next version: open an issue.

Гайд по Spotty

Всё, что умеет строка, — от установки до последней настройки. Читается за десять минут, но можно остановиться после второго раздела.

Установка

  1. Скачайте установщик Файл Spotty-Setup-….exe лежит на странице релизов, либо возьмите его кнопкой на главной.
  2. Запустите Права администратора не нужны. Windows может показать синее окно «Система Windows защитила ваш компьютер» — нажмите Подробнее → Выполнить в любом случае. Так бывает со всеми программами без платной цифровой подписи.
  3. Нажмите Ctrl + E Сразу после установки строка откроется сама. Дальше она живёт в трее, рядом с часами, и вызывается сочетанием Ctrl E из любой программы.

Как устроена строка

Нажали Ctrl E, напечатали, выбрали стрелками, открыли Enter. Закрыть — Esc или клик мимо. Строка не занимает экран и не требует, чтобы с ней что-то сделали.

Дописывать слово до конца не нужно. Spotty сверяет напечатанные буквы со всеми известными названиями, поэтому tele, tlg и eleg одинаково находят Telegram.

Настраивать ничего не надо. Список программ собирается при первом запуске и обновляется в фоне. Пользоваться строкой можно сразу.

Что можно найти

Программы

Всё, что есть в меню «Пуск», включая Калькулятор, Параметры и другие приложения из Магазина. Кроме того, раз в день Spotty просматривает все диски и находит портативные программы и игры, которых в «Пуске» нет. Рядом с ними написана папка — так две копии одной программы легко различить.

Файлы и папки

По умолчанию — с рабочего стола, из Документов и Загрузок. Список папок меняется в настройках. Скрытые файлы и служебные папки вроде node_modules и .git не ищутся специально: они завалили бы собой всё остальное.

Калькулятор

Наберите выражение — ответ появляется прямо по ходу: 12*(3+4)^2, 1920/16*9, sqrt(2). Enter копирует ответ.

Понимает + - * / // % ^ **, скобки, запятую как десятичный знак, × и ÷, константы pi, e, tau и функции sqrt, sin, cos, tan, asin, acos, atan, ln, log, log2, log10, exp, abs, round, floor, ceil, fact.

Команды

Начните запрос с >, и остальное станет командой: > ipconfig /all. Она откроется в новом окне командной строки, так что вывод можно спокойно прочитать, а не ловить взглядом.

Интернет

В конце любой выдачи есть «Искать в Google …», поэтому запрос никогда не упирается в пустоту. Начните с ?, чтобы сразу искать в интернете: ? погода на завтра. Наберите что-то похожее на адрес — github.com — и Spotty предложит открыть сайт, а не искать его. Поисковик выбирается в настройках: Google, Яндекс, DuckDuckGo или Bing.

Ctrl K стоит запомнить. Там собрано всё, что можно сделать с выбранным пунктом: показать в папке, скопировать путь, скопировать имя, открыть там терминал, запустить от администратора, забыть частоту запусков, скрыть из выдачи — и у каждого действия рядом написано его сочетание.

Скрытие обратимо. Пункт, скрытый через Ctrl K, возвращается в «Настройки → Скрытые из результатов». Скрытая папка прячет всё, что в ней лежит, — быстрый способ разобрать шумную выдачу.

Три вещи, которые происходят сами

  • Частое поднимается выше. Если на «t» вы всегда открываете Telegram, в следующий раз он будет первым. «Забыть» в меню действий сбрасывает это для одного пункта.
  • Неверная раскладка не мешает. еудупкфь найдёт Telegram: клавиши на тех же местах, поэтому запрос переводится обратно перед поиском.
  • Сокращения работают. vsc — Visual Studio Code, ntpd — Notepad.

Обновления

Два способа узнать о новой версии, оба выбираются в настройках:

  • Сообщать — в углу экрана появится уведомление. Нажмите на него, и обновление скачается прямо в строке, с полосой прогресса, после чего Spotty перезапустится.
  • Скачивать в фоне — обновление качается, пока вы работаете. Когда оно готово, в строке появляется кнопка «Перезапустить и обновить» и ждёт, пока вы её не нажмёте.

«Проверить обновления» в меню трея всегда качает в фоне.

Где что лежит

  • Настройки — %APPDATA%\Spotty
  • Кэш иконок и списка программ — %LOCALAPPDATA%\Spotty; можно удалить, соберётся заново
  • Скачанное обновление — папка _update рядом со Spotty.exe

Удаление

«Параметры → Приложения → Spotty → Удалить». Установщик спросит, оставить ли настройки, — тогда при повторной установке всё окажется на своих местах.

Если что-то не так

Сочетание занято. Его держит другая программа, часто другой лаунчер. Закройте её или выберите другое сочетание.

Строка открывается медленно. Выключите стеклянный фон. Стекло снимает экран под строкой и размывает его на видеокарте; на старом железе простой тёмный фон быстрее.

Чего-то нет в выдаче. Для файлов — добавьте папку в настройках. Для программ на диске помните, что обход пропускает Windows и ProgramData, Загрузки, git-репозитории и служебные программы: установщики, обновлялки, консольные утилиты. Если программа есть в «Пуске», ищите её под названием оттуда.
