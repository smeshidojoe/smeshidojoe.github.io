Privacy

Short answer: everything stays on your computer, and this page has no trackers.

The app

  • No tracking. Knack does not report what you copy, write, listen to or translate.
  • No account. There is nothing to sign up for.
  • Your data is local. Settings, clipboard history, the shelf and its files, snippets, notes, tasks and the log all live in one folder inside your user profile.
  • Nothing is uploaded. Files you drop on the shelf are copied into that folder and go nowhere else.

When it uses the network

Knack reaches the internet in four cases, and only these four:

  • Updates — it asks GitHub whether a newer release exists.
  • Translator models — downloaded once for each language pair you use offline.
  • ffmpeg — fetched once if you want video and music previews on the shelf. You can switch that off in settings.
  • DeepL — only if you chose it as the translation engine and pasted in your own key. Then the text you translate goes to DeepL, as it would from their own website.

The offline translator sends nothing anywhere: it runs on your machine.

This website

  • Simple static pages on GitHub Pages. No analytics, no trackers, no ads.
  • The site sets no cookies and collects no personal data.
  • Fonts load from Google Fonts, so that request reaches Google with your IP address, like on any site that uses a font service.
  • GitHub hosts the pages and may keep normal server logs. See the GitHub Privacy Statement.

Questions

Something unclear, or something you want changed? Write an issue on GitHub.

Приватность

Коротко: всё остаётся на твоём компьютере, а у этой страницы нет слежки.

Программа

  • Никакой слежки. Knack не сообщает никуда, что ты копируешь, пишешь, слушаешь и переводишь.
  • Никакого аккаунта. Регистрироваться негде и незачем.
  • Данные лежат локально. Настройки, история буфера, полка и её файлы, заготовки, заметки, задачи и лог — всё в одной папке внутри твоего профиля.
  • Ничего не загружается в сеть. Файлы, которые ты бросаешь на полку, копируются в эту папку и больше никуда не уходят.

Когда он выходит в сеть

Knack обращается в интернет в четырёх случаях, и только в них:

  • Обновления — спрашивает у GitHub, есть ли версия новее.
  • Модели переводчика — скачиваются один раз для каждой пары языков, которой ты пользуешься офлайн.
  • ffmpeg — забирается один раз, если нужны превью видео и музыки на полке. В настройках это можно выключить.
  • DeepL — только если ты сам выбрал его движком перевода и вставил свой ключ. Тогда переводимый текст уходит в DeepL, ровно как с их собственного сайта.

Офлайн-переводчик не отправляет никуда ничего: он работает на твоей машине.

Этот сайт

  • Простые статические страницы на GitHub Pages. Ни аналитики, ни счётчиков, ни рекламы.
  • Сайт не ставит куки и не собирает личные данные.
  • Шрифты грузятся из Google Fonts, поэтому этот запрос уходит в Google вместе с твоим IP-адресом — как на любом сайте со шрифтами из сети.
  • Страницы лежат на GitHub, он может вести обычные логи сервера. Подробности — в политике GitHub.
