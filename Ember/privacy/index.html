Privacy

Short answer: the tool has no server, and this page has no trackers.

The tool

  • No tracking. Ember never sends your links, your files or your errors anywhere.
  • No account, no key. There is nothing to sign up for.
  • Direct connection. Your computer talks to the site you asked about. There is no server of ours in between.
  • Files stay with you. Everything Ember downloads is saved on your disk only.

Cookies from your browser

If you ask Ember to use the login from your browser, it reads the needed cookies from your computer and sends them only to that one site. This way the site sees you as signed in.

  • The cookies live in memory while Ember runs. Ember does not save them or write them to a log.
  • They go only to the site you are downloading from.
  • Nothing is sent to the author of this project or to anyone else.

Cookies are like a password. If you save them to a file, keep that file safe.

This website

  • These are simple static pages on GitHub Pages. No analytics, no trackers, no ads.
  • The site sets no cookies and collects no personal data.
  • The fonts come from Google Fonts, so that request reaches Google with your IP address, like on any site that uses a font service.
  • GitHub hosts the pages and may keep normal server logs. See the GitHub Privacy Statement.
  • Links to GitHub, PyPI and other sites follow their own rules.

Questions

Something unclear, or something you want changed? Write an issue on GitHub.

Приватность

Коротко: у программы нет сервера, а у этой страницы нет слежки.

Программа

  • Никакой слежки. Ember никуда не отправляет твои ссылки, файлы и ошибки.
  • Ни аккаунта, ни ключа. Регистрироваться негде и незачем.
  • Прямое соединение. Твой компьютер общается с тем сайтом, о котором ты спросил. Нашего сервера в середине нет.
  • Файлы остаются у тебя. Всё, что Ember скачивает, лежит только на твоём диске.

Куки из браузера

Если попросить Ember взять логин из браузера, он прочитает нужные куки на твоём компьютере и отправит их только на этот один сайт. Так сайт видит, что ты вошёл в аккаунт.

  • Куки живут в памяти, пока Ember работает. Он не сохраняет их и не пишет в лог.
  • Они уходят только на тот сайт, откуда ты качаешь.
  • Автору проекта и кому-либо ещё не уходит ничего.

Куки – это как пароль. Если сохраняешь их в файл, храни этот файл в надёжном месте.

Этот сайт

  • Это простые статические страницы на GitHub Pages. Ни аналитики, ни счётчиков, ни рекламы.
  • Сайт не ставит куки и не собирает личные данные.
  • Шрифты грузятся из Google Fonts, поэтому этот запрос уходит в Google вместе с твоим IP-адресом – как на любом сайте со шрифтами из сети.
  • Страницы лежат на GitHub, он может вести обычные логи сервера. Подробности – в политике GitHub.
  • Ссылки на GitHub, PyPI и другие сайты живут по своим правилам.
