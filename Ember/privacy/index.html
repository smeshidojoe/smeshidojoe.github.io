Privacy

Short version: the library has no backend, and this page has no analytics.

The library

  • No telemetry. Ember never reports usage, URLs, or errors anywhere.
  • No accounts, no API keys. Nothing to sign up for.
  • Direct requests only. Traffic goes from your machine to the platform you asked about. There is no intermediary server operated by this project.
  • Local files only. Downloads, sidecar files and any cache live on your disk.

Cookies read from your browser

When you pass cookies_from_browser or --cookies-from-browser, Ember reads the relevant cookies from the browser profile on your machine and attaches them to requests aimed at that service — so the platform sees your own logged-in session.

  • Cookies are held in memory for the run and are not written to a log or a file by Ember.
  • They are only sent to the platform the request targets.
  • Nothing is transmitted to the author of this project or to any third party.

Cookies are credentials. If you export them with --cookies-file, treat that file the way you would treat a password.

This website

  • Static pages hosted on GitHub Pages. No analytics, no tracking pixels, no advertising.
  • No cookies are set by this site, and no personal data is collected or stored.
  • Fonts are loaded from Google Fonts, so that request reaches Google's servers with your IP address and user agent, as with any site using a font CDN.
  • GitHub, as the host, may keep standard server logs. See the GitHub Privacy Statement.
  • Links to GitHub, PyPI and other external sites are governed by their own policies.
