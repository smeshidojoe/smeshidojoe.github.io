Documentation

Everything needed to pull media out of 19 social platforms – as a library, as a CLI, or as a piece of something bigger.

Installation

Ember needs Python 3.9 or newer. The distribution is named ember-dl, the import name stays ember:

pip
pip install ember-dl

Latest development version straight from Git:

pip · git
pip install git+https://github.com/smeshidojoe/Ember.git

After installation both the Python API (import ember) and the ember command are available. The only required dependency is requests.

When you need ffmpeg

Most downloads work without it. Put ffmpeg on your PATH if you need:

  • muxing separate video + audio tracks (results with kind="merge");
  • audio-only extraction (audio_only=True / --audio-only);
  • writing metadata into the file (embed_metadata=True).

Direct mp4 and single-stream HLS assemble on their own. Check at runtime with ember.ffmpeg_available().

Quick start

Two steps: extract, then optionally download. extract() never fetches media bytes – it only resolves links and metadata.

quickstart.py
import ember

# 1) direct links and metadata
result = ember.extract("https://vimeo.com/76979871")
print(result.title, result.author, result.thumbnail)
for m in result.media:
    print(m.kind, m.quality, m.url)

# 2) let Ember save the file
def on_progress(p: ember.DownloadProgress):
    if p.fraction is not None:
        print(f"{p.fraction*100:.0f}%")

paths = ember.download(
    result, "downloads/",
    max_height=720,          # cap quality
    concurrency=6,           # parallel HLS segments
    on_progress=on_progress,
    embed_metadata=True,     # title/author (ffmpeg)
)

Useful checks before committing to a download:

checks.py
ember.can_extract(url)                       # is the link supported
ember.available_qualities(result.media[0])   # [1080, 720, 480]
ember.probe_size(result.media[0])            # bytes, one HEAD-ish request
ember.ffmpeg_available()                    # is ffmpeg on PATH
ember.supported_services()                  # list of service names

Command line

Quote the URL. Flag order doesn't matter. Without -d nothing is downloaded – the command only prints links and metadata.

terminal
# show direct links and metadata
ember "https://x.com/user/status/123456789"

# same, as JSON
ember "https://www.tiktok.com/@user/video/7123456789" --json

# DOWNLOAD: -d enables it (name from the site, current folder)
ember -d "https://vimeo.com/76979871"

# custom file name (-o) and folder (-p)
ember -d -o myclip -p downloads "https://vimeo.com/76979871"

# cap quality, fetch HLS in 6 threads
ember -d -p downloads --max-height 720 --concurrency 6 "<url>"

# audio only + write metadata into the file (needs ffmpeg)
ember -d --audio-only --embed-metadata "<soundcloud url>"

# a whole playlist / set
ember -d --playlist "https://soundcloud.com/user/sets/name"

# links from a file, one per line (# = comment); fetched in parallel
ember -d -a links.txt

# Instagram story highlights of a profile (needs cookies)
ember -d --highlights --cookies-from-browser firefox "https://www.instagram.com/USER/"

# resume a batch politely: keep finished files, cap the speed
ember -d -a links.txt --skip-existing --rate-limit 1000000

List available qualities and exit without downloading: ember -F "<url>". Full help: ember --help.

Quality & formats

A Result holds one or more Media objects. Progressive media carry alternative heights in variants; HLS media resolve their ladder from the master manifest.

quality.py
heights = ember.available_qualities(result.media[0])   # [1080, 720, 480]

# cap the whole download
ember.download(result, "out/", max_height=720)

# or one media item, with your own filename
path = ember.download_media(result.media[0], "out/clip.mp4",
                            max_height=720, concurrency=6)
Building a UI? probe_size() returns the byte size using the same access profile as the real download, so a size shown in your quality selector is the size the user gets.

Cookies

Some content is only served to logged-in users: NSFW tweets, private and full-quality Instagram posts, closed VK groups, most Facebook video. Ember reads cookies straight from a browser.

cookies
# Python
result = ember.extract(url, cookies_from_browser="firefox")
result = ember.extract(url, cookies={"auth_token": "…", "ct0": "…"})

# CLI
ember --cookies-from-browser firefox "<url>"
ember --cookies "auth_token=…; ct0=…" "<url>"
ember --cookies-file cookies.txt "<url>"       # Netscape format

Which browser to use

  • Firefox – recommended, reads out of the box on any OS.
  • Vivaldi, Opera and other non-Chrome Chromium browsers on Windows also work.
  • Recent Chrome, Edge, Brave encrypt their cookie store (App-Bound Encryption) and usually cannot be read.
Tip – keep a dedicated cookies browser. Install a browser you don't otherwise use, sign in to the services you plan to pull from, then leave it closed. The sessions stay valid, and your main browser is never touched.

Pick a profile with browser_profile= / --browser-profile. The reader is native and needs no extra packages.

Playlists & timelines

A playlist is a set (currently SoundCloud sets). A timeline is an author's latest posts, resolved from a profile or channel URL.

bulk.py
if ember.supports_playlist(url):
    for entry in ember.extract_playlist(url).entries:
        ember.download(entry, "downloads/")

# latest posts by profile URL, e.g. "https://x.com/nasa"
if ember.supports_timeline(url):
    for entry in ember.extract_timeline(url, limit=30).entries:
        ember.download(entry, "downloads/")

Timelines are supported for Twitter/X, Instagram, Vimeo, SoundCloud, Pinterest, Tumblr, Rutube, VK and Twitch. The first two may need cookies.

Instagram profiles also expose their story highlights through extract_highlights() – see the reference.

Embedding Ember

Check whether a link is supported, extract it, and handle the one error type Ember can raise.

embed.py
import ember

def fetch(url: str, out_dir: str):
    if not ember.can_extract(url):
        return None                        # not a supported link
    try:
        result = ember.extract(url)
    except ember.EmberError:
        return None
    return ember.download(result, out_dir, concurrency=6)
Media objects carry http_headers. If you hand URLs to your own downloader instead of using download(), pass those headers along – TikTok answers 403 without them.

API – extraction

extract(url, *, timeout=15.0, proxies=None, cookies=None, cookies_from_browser=None, browser_profile=None, session=None) → Result

Extract direct media links and metadata from a post URL.

  • url – post / track / video link.
  • timeout – per-request timeout in seconds.
  • proxies – requests-style dict, e.g. {"https": "http://host:port"}.
  • cookies – {name: value} for private or NSFW content.
  • cookies_from_browser – "firefox", "vivaldi", "chrome", …
  • session – bring your own requests.Session.
  • raises UnsupportedUrlError, NetworkError, ExtractionError.

extract_many(urls, *, workers=6, **kwargs) → list[tuple]

Extract many links at once, in parallel. Returns [(url, result, error), …] in the same order as the input: on success error is None, on failure result is None. One dead link never stops the batch, and on a mixed batch this is roughly two to three times faster than a loop.

batch.py
for url, res, err in ember.extract_many(links):
    if err:
        print("skip", url, err.reason)
    else:
        ember.download(res, "downloads/")

Keep workers modest – services rate-limit. The command line uses this automatically for a batch file of plain links.

extract_playlist(url, **kwargs) → Playlist

Extract a set or playlist. A single link yields a Playlist with one entry.

extract_timeline(url, *, limit=30, **kwargs) → Playlist

List an author's latest posts by profile or channel URL, up to limit.

extract_highlights(url, *, limit=30, **kwargs) → Playlist

List a profile's story highlights – the pinned covers above the posts – from a profile URL. One entry per highlight, each a "gallery" result holding that collection's stories, with title set to the highlight's name. Instagram only, and it needs account cookies.

highlights.py
pl = ember.extract_highlights("https://www.instagram.com/USER/", limit=5,
                              cookies_from_browser="firefox")
for entry in pl.entries:
    print(entry.title, len(entry.media))
    ember.download(entry, "downloads/")

can_extract(url) → bool

True when the URL matches a supported service.

supports_playlist(url) → bool · supports_timeline(url) → bool · supports_highlights(url) → bool

Whether playlist, timeline or highlight extraction is available for that URL.

supported_services() → list[str]

Names of all available services.

API – download

download(result, out_dir=".", *, filename=None, max_height=None, concurrency=1, on_progress=None, audio_only=False, embed_metadata=False, subtitles=False, thumbnail=False, write_info=False, skip_existing=False, rate_limit=None) → list[str]

Download an entire Result. Returns the paths written.

  • filename – base name without extension (default: from metadata).
  • max_height – cap quality by height, e.g. 720.
  • concurrency – parallel workers: HLS segments for one file, or the items of a gallery. Output order and names stay the same whatever you pass.
  • on_progress – callback receiving DownloadProgress.
  • audio_only, embed_metadata – need ffmpeg. Metadata is written to video and audio only; photos are left untouched.
  • subtitles, thumbnail, write_info – extra sidecar files.
  • skip_existing – keep a file that is already there and skip the download; its path is still returned, so the result list stays complete.
  • rate_limit – cap the total speed in bytes per second, e.g. 1_000_000 for about 1 MB/s. One budget is shared by every worker, so raising concurrency does not multiply it.

A failing item inside a gallery is logged and skipped; a single-media failure raises.

download_media(media, out_path, *, max_height=None, concurrency=1, on_progress=None, resume=True, audio_only=False, skip_existing=False, limiter=None, meta=None) → str

Download a single Media. Returns the actual path – the extension may become .ts when ffmpeg is missing.

RateLimiter(rate)

Caps total bytes per second and is safe to share between threads. download() builds one for you from rate_limit; make your own only to hold several download_media() calls to one shared budget.

limit.py
limiter = ember.RateLimiter(500_000)          # 500 KB/s for both files
ember.download_media(a, "a.mp4", limiter=limiter)
ember.download_media(b, "b.mp4", limiter=limiter)

available_qualities(media, *, exclude=(), ascending=False) → list[int]

Available heights, highest first. exclude drops the ones your interface hides (heights the media does not have are ignored); ascending flips the order. Any value from the list goes straight back into max_height.

probe_size(media) → int | None · ffmpeg_available() → bool

Byte size before downloading, and whether ffmpeg is on PATH.

cookies_from_browser(browser, service=None, profile=None, domains=None) → dict

Read cookies from a browser. service limits them to that service's domains and raises on an unknown name; domains takes explicit domain substrings such as ["youtube.com"] and works for sites Ember does not support. It also raises when the browser is running and holding its cookie database open.

cookies_from_file(path) → dict

Read a Netscape cookies.txt file. extract() takes the path directly too: ember.extract(url, cookies="cookies.txt").

API – data models

Result

  • service: str, source_url: str.
  • kind: str – "single", "merge" (separate video+audio, needs ffmpeg) or "gallery".
  • media: list[Media], subtitles: list[Subtitle].
  • title, author, thumbnail, filename_hint – all optional.
  • duration, timestamp, view_count, like_count – when the service reports them.
  • is_preview: bool – true when the site only handed over a shortened version (a SoundCloud Go+ track gives a 30 second snippet). duration then describes the snippet, and full_duration holds the length of the whole thing when it is known.
  • requires_merge: bool (property), to_dict().

Media

  • kind – "video", "audio", "photo" or "gif".
  • url, ext, quality.
  • http_headers: dict – pass these to your own downloader.
  • variants: list[MediaVariant] – other progressive qualities.

Playlist · Subtitle · MediaVariant

Playlist holds entries: list[Result] plus service and title. Subtitle has lang, url, ext. MediaVariant has url, height, quality, ext.

DownloadProgress

Passed to on_progress: downloaded, total, segments_done, segments_total, stage ("download" / "mux" / "metadata") and the fraction property. Speed and ETA are not fields – time them yourself:

speed.py
import time
start = time.time()

def on_progress(p: ember.DownloadProgress):
    if not p.total:                  # HLS / unknown size
        return
    speed = p.downloaded / (time.time() - start)
    eta = (p.total - p.downloaded) / speed if speed else 0
    print(f"{p.fraction*100:5.1f}%  {speed/1048576:.2f} MiB/s  ETA {int(eta)}s")

API – errors

Everything inherits from EmberError, so one except covers the library:

  • UnsupportedUrlError – the link is not from a supported service.
  • NetworkError – transport failure, timeout, blocked IP.
  • ExtractionError – the page loaded but no media could be resolved.

ExtractionError.reason

Why it failed, in a form your code can branch on instead of reading the English message. The values live on ember.Reason:

ReasonMeaningWhat to do
NEEDS_AUTHcookies or a login are requiredoffer to sign in, pass cookies
RESTRICTEDage wall, members-only or paid tiertell the user access is missing
DELETEDremoved, private, or never existeddrop the link
GEOBLOCKEDblocked in this regionretry through a proxy
RATE_LIMITEDtoo many requestswait and try again later

__version__

The installed version as a string – the same value ember --version prints.

API – logging

Ember logs to the ember logger (children: ember.router, ember.http, ember.cookies, ember.download) and is silent by default via NullHandler.

logging.py
import logging
logging.basicConfig()
logging.getLogger("ember").setLevel(logging.INFO)   # or DEBUG

On the CLI use -v for stderr logs and -vv for debug.

Limitations

  • Instagram – without cookies you often get only a preview; with cookies, full quality.
  • Reddit, Newgrounds, OK.ru – sometimes refuse requests; proxies= / --proxy helps.
  • Facebook – public video usually still needs cookies.
  • Twitter / X – 18+ posts need account cookies (auth_token and ct0).
  • Twitch – clips only, not VODs or live streams.

Всё, что нужно, чтобы забирать медиа с 19 сайтов – в коде, в терминале или внутри своего проекта.

Установка

Нужен Python 3.9 или новее. Пакет называется ember-dl, а в коде пишется ember:

pip
pip install ember-dl

pip · git

Когда нужен ffmpeg

Почти всё работает без него. Положи ffmpeg в PATH, если хочешь:

  • склеить видео с отдельной звуковой дорожкой;
  • сохранить только звук;
  • записать название и автора внутрь файла.

Проверить из кода: ember.ffmpeg_available().

Два шага: найти медиа, потом при желании скачать. Поиск ничего не качает.

Командная строка

Ссылку бери в кавычки. Порядок флагов не важен. Без -d ничего не скачивается – ты просто видишь ссылки и данные.

terminal
# показать ссылки и данные
ember "https://x.com/user/status/123456789"

# то же самое в JSON
ember "https://www.tiktok.com/@user/video/7123456789" --json

# СКАЧАТЬ: включает -d
ember -d "https://vimeo.com/76979871"

# своё имя файла (-o) и папка (-p)
ember -d -o myclip -p downloads "https://vimeo.com/76979871"

# размер поменьше, по 6 частей сразу
ember -d -p downloads --max-height 720 --concurrency 6 "<url>"

# только звук, с названием внутри файла (нужен ffmpeg)
ember -d --audio-only --embed-metadata "<soundcloud url>"

# целый плейлист
ember -d --playlist "https://soundcloud.com/user/sets/name"

# много ссылок из файла, по одной в строке; забираются параллельно
ember -d -a links.txt

# актуальное из профиля Instagram (нужны куки)
ember -d --highlights --cookies-from-browser firefox "https://www.instagram.com/USER/"

# продолжить пачку аккуратно: не трогать готовое, ограничить скорость
ember -d -a links.txt --skip-existing --rate-limit 1000000

Посмотреть доступные размеры и остановиться: ember -F "<url>". Вся справка: ember --help.

Качество и размер

В одном посте может быть несколько файлов. Видео обычно есть в нескольких размерах, и ты выбираешь нужный.

quality.py
heights = ember.available_qualities(result.media[0])   # [1080, 720, 480]

# ограничить всю загрузку
ember.download(result, "out/", max_height=720)

# или один файл, со своим именем
path = ember.download_media(result.media[0], "out/clip.mp4",
                            max_height=720, concurrency=6)
Делаешь выбор качества в своём интерфейсе? probe_size() спрашивает сайт так же, как настоящая загрузка, поэтому показанный размер совпадёт с реальным.

Куки

Часть контента видят только те, кто вошёл в аккаунт: посты 18+ в X, полное качество в Instagram, закрытые группы во ВКонтакте, почти все видео в Facebook. Ember умеет брать логин из браузера.

cookies
# Python
result = ember.extract(url, cookies_from_browser="firefox")
result = ember.extract(url, cookies={"auth_token": "…", "ct0": "…"})

# командная строка
ember --cookies-from-browser firefox "<url>"
ember --cookies "auth_token=…; ct0=…" "<url>"
ember --cookies-file cookies.txt "<url>"

Какой браузер выбрать

  • Firefox – работает на любой системе, это самый простой вариант.
  • Vivaldi, Opera и другие браузеры на Chromium под Windows тоже подойдут.
  • Новые Chrome, Edge, Brave закрывают свои данные, поэтому обычно не работают.
Совет: держи для этого отдельный браузер. Поставь браузер, которым больше нигде не пользуешься, войди в аккаунты нужных сайтов и просто не открывай его. Логины останутся живыми, а основной браузер это не заденет.

Выбрать профиль можно через browser_profile= или --browser-profile.

Плейлисты и профили

Плейлист – это набор треков. Профиль даёт свежие посты одного автора.

bulk.py
if ember.supports_playlist(url):
    for entry in ember.extract_playlist(url).entries:
        ember.download(entry, "downloads/")

# свежие посты, например "https://x.com/nasa"
if ember.supports_timeline(url):
    for entry in ember.extract_timeline(url, limit=30).entries:
        ember.download(entry, "downloads/")

Профили работают для Twitter/X, Instagram, Vimeo, SoundCloud, Pinterest, Tumblr, Rutube, VK и Twitch. Первым двум могут понадобиться куки.

У профилей Instagram можно забрать ещё и актуальное – через extract_highlights(), см. справочник.

Встроить в свой проект

Проверь, поддерживается ли ссылка, забери медиа и поймай единственный тип ошибки.

embed.py
import ember

def fetch(url: str, out_dir: str):
    if not ember.can_extract(url):
        return None                        # ссылка не поддерживается
    try:
        result = ember.extract(url)
    except ember.EmberError:
        return None
    return ember.download(result, out_dir, concurrency=6)
У каждого медиа есть http_headers. Если качаешь файл сам, а не через download(), передавай эти заголовки – без них TikTok ответит ошибкой.

Поиск медиа

extract(url, *, timeout=15.0, proxies=None, cookies=None, cookies_from_browser=None, browser_profile=None, session=None) → Result

Забирает ссылки и данные из поста.

  • url – ссылка на пост, трек или видео.
  • timeout – сколько секунд ждать один запрос.
  • proxies – настройки прокси, например {"https": "http://host:port"}.
  • cookies – {имя: значение} для закрытого контента.
  • cookies_from_browser – "firefox", "vivaldi", "chrome" и так далее.
  • session – своя requests.Session.
  • может выбросить UnsupportedUrlError, NetworkError, ExtractionError.

extract_many(urls, *, workers=6, **kwargs) → list[tuple]

Забирает сразу много ссылок, параллельно. Возвращает [(url, result, error), …] в том же порядке, что и на входе: при успехе error – None, при ошибке None будет в result. Одна битая ссылка не рушит всю пачку, а на смешанном наборе это в два-три раза быстрее обычного цикла.

batch.py
for url, res, err in ember.extract_many(links):
    if err:
        print("пропуск", url, err.reason)
    else:
        ember.download(res, "downloads/")

Не задирай workers – сайты ограничивают частоту запросов. В командной строке это включается само для файла со списком обычных ссылок.

extract_playlist(url, **kwargs) → Playlist

Забирает весь набор. Одиночная ссылка даст плейлист из одного элемента.

extract_timeline(url, *, limit=30, **kwargs) → Playlist

Забирает свежие посты автора, не больше limit.

extract_highlights(url, *, limit=30, **kwargs) → Playlist

Забирает актуальное из профиля – те самые кружки над постами. Один элемент на каждую подборку, каждый – результат вида "gallery" с историями внутри, а в title лежит название подборки. Только Instagram, и нужны куки аккаунта.

highlights.py
pl = ember.extract_highlights("https://www.instagram.com/USER/", limit=5,
                              cookies_from_browser="firefox")
for entry in pl.entries:
    print(entry.title, len(entry.media))
    ember.download(entry, "downloads/")

can_extract(url) → bool

True, если ссылка с поддерживаемого сайта.

supports_playlist(url) → bool · supports_timeline(url) → bool · supports_highlights(url) → bool

Говорит, можно ли забрать по ссылке плейлист, профиль или актуальное.

supported_services() → list[str]

Названия всех поддерживаемых сайтов.

Скачивание

download(result, out_dir=".", *, filename=None, max_height=None, concurrency=1, on_progress=None, audio_only=False, embed_metadata=False, subtitles=False, thumbnail=False, write_info=False, skip_existing=False, rate_limit=None) → list[str]

Скачивает всё из результата и возвращает пути сохранённых файлов.

  • filename – имя без расширения (по умолчанию берётся из поста).
  • max_height – ограничить размер, например 720.
  • concurrency – сколько потоков: части одного файла или элементы галереи. Порядок и имена файлов не меняются, какое бы число ты ни поставил.
  • on_progress – твоя функция, её вызывают по ходу загрузки.
  • audio_only, embed_metadata – нужен ffmpeg. Данные пишутся только в видео и аудио, фотографии остаются нетронутыми.
  • subtitles, thumbnail, write_info – дополнительные файлы рядом с основным.
  • skip_existing – если файл уже есть, оставить его и не качать заново; путь всё равно вернётся, так что список результатов остаётся полным.
  • rate_limit – ограничить общую скорость в байтах в секунду, например 1_000_000 – это примерно 1 МБ/с. Лимит один на всю загрузку, поэтому concurrency его не умножает.

Сломанный элемент внутри галереи пропускается с записью в лог; ошибка одиночного файла выбрасывается.

download_media(media, out_path, *, max_height=None, concurrency=1, on_progress=None, resume=True, audio_only=False, skip_existing=False, limiter=None, meta=None) → str

Скачивает один файл и возвращает реальный путь. Без ffmpeg расширение может стать .ts.

RateLimiter(rate)

Ограничивает общую скорость в байтах в секунду, им можно пользоваться из нескольких потоков. download() создаёт его сам из rate_limit; свой нужен только чтобы посадить несколько вызовов download_media() на один общий лимит.

limit.py
limiter = ember.RateLimiter(500_000)          # 500 КБ/с на оба файла
ember.download_media(a, "a.mp4", limiter=limiter)
ember.download_media(b, "b.mp4", limiter=limiter)

available_qualities(media, *, exclude=(), ascending=False) → list[int]

Доступные размеры, от большего к меньшему. exclude убирает те, которые ты прячешь в своём интерфейсе (размеры, которых нет, просто игнорируются), ascending переворачивает порядок. Любое значение из списка можно сразу отдать в max_height.

probe_size(media) → int | None · ffmpeg_available() → bool

Размер файла до загрузки и наличие ffmpeg в PATH.

cookies_from_browser(browser, service=None, profile=None, domains=None) → dict

Читает куки из браузера. service ограничивает их доменами этого сайта и падает с ошибкой на незнакомом имени; domains принимает домены явно, например ["youtube.com"], и работает даже для сайтов, которые Ember не поддерживает. Ошибка будет и если браузер запущен и держит базу куки занятой.

cookies_from_file(path) → dict

Читает файл cookies.txt в формате Netscape. Путь можно отдать и прямо в extract(): ember.extract(url, cookies="cookies.txt").

Что приходит в ответ

Result

  • service, source_url – сайт и исходная ссылка.
  • kind – "single", "merge" (видео и звук отдельно, нужен ffmpeg) или "gallery".
  • media – список файлов. subtitles – дорожки субтитров.
  • title, author, thumbnail, filename_hint – могут быть пустыми.
  • duration, timestamp, view_count, like_count – если сайт их отдаёт.
  • is_preview – правда, когда сайт отдал только укороченную версию (трек SoundCloud Go+ даёт 30 секунд). Тогда duration – длина отрывка, а в full_duration лежит длина целого, если она известна.
  • requires_merge, to_dict().

Media

  • kind – "video", "audio", "photo" или "gif".
  • url, ext, quality.
  • http_headers – передавай их, если качаешь файл сам.
  • variants – тот же файл в других размерах.

Playlist · Subtitle · MediaVariant

В Playlist лежит entries – список результатов. У Subtitle есть lang, url, ext. У MediaVariant – url, height, quality, ext.

DownloadProgress

Приходит в on_progress: downloaded, total, segments_done, segments_total, stage и fraction. Скорости и оставшегося времени тут нет – посчитай сам:

speed.py
import time
start = time.time()

def on_progress(p: ember.DownloadProgress):
    if not p.total:                  # размер ещё не известен
        return
    speed = p.downloaded / (time.time() - start)
    eta = (p.total - p.downloaded) / speed if speed else 0
    print(f"{p.fraction*100:5.1f}%  {speed/1048576:.2f} MiB/s  ETA {int(eta)}s")

Ошибки

Все ошибки наследуются от EmberError, так что хватит одного except:

  • UnsupportedUrlError – ссылка не с поддерживаемого сайта.
  • NetworkError – нет связи, таймаут или сайт заблокировал.
  • ExtractionError – страница открылась, но медиа не нашлось.

ExtractionError.reason

Причина в виде значения, по которому можно ветвиться в коде, вместо разбора английского текста. Значения лежат в ember.Reason:

ПричинаЧто значитЧто делать
NEEDS_AUTHнужны куки или вход в аккаунтпредложить войти, передать куки
RESTRICTED18+, только для подписчиков или платноесказать пользователю, что доступа нет
DELETEDудалено, закрыто или не существоваловыбросить ссылку
GEOBLOCKEDзаблокировано в этом регионепопробовать через прокси
RATE_LIMITEDслишком много запросовподождать и повторить позже

__version__

Установленная версия строкой – то же самое, что печатает ember --version.

Ограничения

  • Instagram – без куки часто приходит только маленькое превью.
  • Reddit, Newgrounds, OK.ru – иногда отклоняют запросы; поможет прокси.
  • Facebook – даже публичному видео обычно нужны куки.
  • Twitter / X – для постов 18+ нужны куки.
  • Twitch – только клипы, не трансляции.
