Media extraction that burns clean.

Ember is an embeddable Python library and CLI. Give it a post URL — it returns direct media URLs and metadata, and downloads them itself, HLS included.

A compact alternative to cobalt. No yt-dlp requirement, no browser automation, no service you have to keep running. Just requests and a few hundred KB of code.

quickstart.py 
import ember

result = ember.extract("https://vimeo.com/76979871")
print(result.title, result.author)

# direct URLs, ready to hand anywhere
for m in result.media:
    print(m.kind, m.quality, m.url)

# …or let Ember download it
paths = ember.download(
    result, "downloads/",
    max_height=720,
    concurrency=6,
)

01 — What you get

Small surface, serious reach

Ember calls the same internal APIs the sites use in the browser, parses out real media links, and hands them to you as typed objects.

🔗

Links or files — your call

extract() gives you direct URLs and metadata. download() pulls the bytes when you want them. Use one, both, or wire the URLs into your own downloader.

📺

HLS without ceremony

Built-in manifest parser fetches segments in parallel and assembles the file. Single streams need no ffmpeg at all.

🧩

Embeddable by design

Typed, py.typed shipped, silent logging, one error base class. Drop it into a bot or a service and fall back to yt-dlp when a link isn't supported.

🍪

Cookies from your browser

Native reader for Firefox on any OS and Chromium-family on Windows — no extra packages. Unlocks private posts and age-gated content.

🎚️

Quality you choose

available_qualities() lists heights, max_height caps them, probe_size() tells you the byte size before a single frame is fetched.

📚

Playlists and timelines

Pull a whole SoundCloud set, or the latest posts from a profile on nine different platforms, and iterate them like any other result.

02 — Two ways in

Library or command line

The same engine either way. Install once — import ember and the ember command both become available.

progress.py 
import ember

def on_progress(p: ember.DownloadProgress):
    if p.fraction is not None:
        print(f"{p.fraction*100:.0f}%")

result = ember.extract(url, cookies_from_browser="firefox")

ember.download(
    result, "downloads/",
    concurrency=6,
    on_progress=on_progress,
    embed_metadata=True,
)
terminal 
# show direct links and metadata — nothing is downloaded
ember "https://x.com/user/status/123456789"

# -d turns downloading on
ember -d "https://vimeo.com/76979871"

# cap quality, 6 parallel HLS segments, custom folder
ember -d -p downloads --max-height 720 --concurrency 6 "<url>"

# audio only, metadata written into the file
ember -d --audio-only --embed-metadata "<soundcloud url>"

# private / NSFW content via browser cookies
ember -d --cookies-from-browser firefox "<url>"

05 — Questions

Frequently asked

How is this different from yt-dlp?

Different job. yt-dlp is an enormous, exhaustive downloader. Ember is a small embeddable extractor for social platforms: it hands you direct URLs and metadata as typed Python objects, with one required dependency. Many projects use both — Ember first, yt-dlp as the fallback for anything it can't parse.

Do I need ffmpeg?

Not usually. Direct mp4 and single-stream HLS assemble without it. You need ffmpeg for muxing separate video+audio tracks (kind="merge"), audio_only, and embed_metadata.

Why does Instagram only give me a preview?

Anonymous requests often return a low-quality preview. Pass cookies — cookies_from_browser="firefox" — and you get full quality. The same applies to NSFW tweets, closed VK groups and most Facebook video.

Some sites return nothing at all.

Reddit, Newgrounds and OK.ru block anonymous requests from datacenter and VPN addresses. They work from a normal home IP, or through proxies= / --proxy.

Which browsers can it read cookies from?

Firefox on any OS works out of the box, as do Chromium-family browsers on Windows such as Vivaldi and Opera. Recent Chrome, Edge and Brave encrypt their cookie store (App-Bound Encryption) and usually cannot be read.

Can I use it in my own bot or app?

That's what it's built for. MIT licensed, typed, silent by default. See the embedding pattern in the docs.
